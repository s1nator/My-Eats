# Диагностика Semantic Navigator / OpenRouter

Проверка 30.10.2026. Массовая индексация не запускалась.

- Короткая строка: HTTP 200, 2 токена, 1024 измерения.
- Первый исторический сбой, `_yaml/__init__.py`: сейчас HTTP 200, 382 токена. Причина исторического ответа 400 не установлена.
- Последний сбой, `alembic/autogenerate/api.py`, строки 1–80 с контекстным заголовком: HTTP 400, 595 токенов.
- Сообщение провайдера: `Embedding input has 595 tokens, exceeding the model maximum of 512.`
- Тот же чанк, укороченный до 315 токенов: HTTP 200.
- Все 10 чанков последнего файла: 595, 427, 587, 742, 692, 638, 641, 682, 677, 677 токенов. Превышение у 9.

Токены посчитаны официальным tokenizer.json LiquidAI/LFM2.5-Embedding-350M, без усечения, со специальными токенами. Результаты совпали с usage и ошибкой провайдера. Ограничитель исходного движка работает только для C# и использует приблизительный бюджет 1024; Python разбивается по 80 строк без проверки токенов. Исключение зависимостей не гарантирует соблюдения 512 токенов собственным кодом проекта.

## Исключение зависимостей

`semanticNavigator.enginePath` в настройках workspace указывает на локальный `semantic-engine` в этой папке. Он собран из установленной версии 0.1.0 с единственным изменением обхода директорий, сохранённым в `engine-exclusions.patch`. Оригинал установленного расширения и его исходники не изменены.

Дополнительно исключены `.venv`, `venv`, `env`, `.env`, `site-packages`, `dist-packages`, `vendor`, `__pycache__`, `.tox`, `.nox`, `.diagnostics`. Существующее исключение `node_modules` сохранено. `.gitignore` и VS Code files.exclude движком не поддерживаются. Локальный обход после изменения: 28 файлов, зависимостей 0 (до изменения в журнале 2702). Существующие тесты engine, provider, chunker прошли.

Локальный бинарник, токенизатор и Python-кэш исключены из Git. Путь к бинарнику абсолютный для этой машины. Для пересборки примените patch к копии исходников engine и выполните `go build -o <workspace>/.diagnostics/semantic-engine ./cmd/engine`. Индексация остаётся выключенной; включение не выполнялось. Старый индекс не очищался.

## Повторение точечной проверки

`python3 .diagnostics/openrouter_probe.py` — короткая строка, затем первый исторический проблемный чанк (два запроса).

`python3 .diagnostics/probe_latest.py` — первый чанк последнего проблемного файла и его укороченная версия (два запроса). Нужен пакет tokenizers и локальный tokenizer.json.

Ключ читается только из существующих настроек, не изменяется и не сохраняется отдельно. Скрипты выводят очищенные ошибки, размеры и usage; тексты входов и заголовки не печатаются. Диагностические запросы отправляют выбранные чанки настроенному провайдеру, как исходное расширение.
